# Frequently asked questions

## Does Pelita need the internet during a service?

No. Pelita uses local services and imported media. Download and install the app ahead of time, then rehearse offline on the actual computer.

## Does Pelita include hymnbooks or LPMI songs?

No. The current app lets you create text slides and import your own permitted files. A searchable library and optional LPMI integration are planned; any LPMI distribution depends on permissions.

## Can I open a PowerPoint file directly?

No. Export it to PDF first, then use **Import files**. Check the PDF because animations and embedded media are not preserved as live effects.

## Can I play music while moving through lyrics?

Yes. Select a slide item and use **Attach MP3**. When you **Take** it, you can move through its slides while the MP3 continues. Use **Audio** controls to pause or restart it.

## What does “Take” mean?

**Take** sends the selected playlist item to the audience display. Selecting or privately previewing an item does not change what is live.

## Is Pelita an official Seventh-day Adventist application?

No. It is an independent open-source project designed with Adventist worship workflows in mind, and other churches may use it.

## Where can I get help or suggest an improvement?

Start with [Troubleshooting](troubleshooting.md). You can also [open a GitHub issue](https://github.com/DyDxdYdX/Pelita/issues) with a bug report or feature request. See [Contributing](../../CONTRIBUTING.md).
