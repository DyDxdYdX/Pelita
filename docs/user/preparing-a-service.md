# Preparing a service

Prepare and rehearse the playlist before Sabbath worship so the operator can focus on the service.

## Build the playlist

1. In **Playlist**, use **New service** to make a service, or **Duplicate service** to reuse last week's order. Select saved services from the menu above the playlist.
2. Select **Text slides** for lyrics, Scripture, or announcements. Give the item a clear title. Put `---` on a line by itself to start each new slide.
3. Use **Import files** to add local images, PDF pages, MP3 tracks, or MP4 videos. A PDF becomes a set of static slides. Export PowerPoint presentations to PDF before importing them.
4. Select an item and use **Move item up** or **Move item down** to match the order of worship. Use **Edit item** to change its title or text. Pelita saves service changes locally.

For example, place an opening hymn, Scripture reading, announcements, a sermon PDF, and closing hymn in order. Keep a separate text slide ready for a last-minute announcement.

## Add accompaniment to lyrics

Select a text or image slide item, then choose **Attach MP3** in **Audio**. You can use **Test audio** before projecting, when no other audio is active. When you **Take** that item, the track plays while you advance its lyrics manually. Use the **Audio** controls to pause, restart, and change volume. Advancing slides or using **Black** does not pause accompaniment; **Clear** stops it.

## Check before the service

1. Press **Run preflight**. If **Missing assets** appears, choose **Relink** to supply a replacement of the same media type, or **Skip** to remove that item from this service.
2. Select every item and check **Preview**. Test an MP3 and preview any video while preparing; video preview is muted.
3. Confirm the correct projector and test the speakers. Walk through the entire playlist in order, especially transitions between Scripture slides and a sermon PDF.
4. Prepare a fallback: a text slide if a video will not play, or an exported PDF if a PowerPoint file cannot be imported. Keep the original files accessible for recovery.

See [Media support](media-support.md) for accepted files and [Presenting](presenting.md) for live controls.
