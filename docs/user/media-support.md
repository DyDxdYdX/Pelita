# Media support

Pelita works with files stored on the computer, so prepared services do not need an internet connection. Import a copy of the file through **Import files**; keep the originals and a backup of your service materials.

| File | How Pelita uses it |
| --- | --- |
| PNG, JPG, JPEG | Static image slides. Files selected together form a slide item. |
| PDF | Static pages converted into image slides during import. |
| MP3 | A standalone audio item, or accompaniment attached to a slide item with **Attach MP3**. |
| MP4 | A video item. Playback depends on your computer's decoder. |

PowerPoint (`.pptx`) is not imported directly. Export it to PDF, check the exported pages, then import the PDF. Animations, transitions, and embedded media from PowerPoint will not carry over as live effects.

Pelita checks files during import, but a file that opens on one computer may fail on another because media decoding differs. Test every MP3 and MP4 on the computer and speakers used for worship. The current pilot expects common H.264/AAC MP4 files; compatibility is still being validated across systems.

PDFs may be up to 64 MiB and 100 pages. Images may be up to 24 MiB each. One import can include up to 100 prepared files and 512 MiB of data. If an import is rejected, try a smaller file or fewer pages. For a video fallback, prepare a text slide or PDF with the essential message.
