# Presenting a service

The **Preview** shows the selected playlist item privately. **Live output** shows what Pelita has sent to the audience. Selecting an item does not display it; **Take** does.

## Use an extended projector display

1. Connect the projector and set your computer to use an extended desktop.
2. In **Projector**, choose the audience display, then press **Confirm display**. The output opens in black. Check the physical screen before continuing.
3. Select the opening item in **Playlist**, review **Preview**, and press **Take**.
4. Use **Previous live slide** and **Next live slide** in **Live output** to move through lyrics or a PDF. You can select and preview another playlist item without changing the current live item.
5. Press **Take** when it is time to switch from Scripture slides to the sermon presentation or another item.

**Black** hides the current image temporarily. **Restore** reveals that live item again. **Clear** removes the live item and stops its audio. **Close output** closes the presentation window.

## Single or mirrored presentation

If no separate audience display is available, select a playlist item, choose **Single / mirrored**, read the warning, and press **Open in black**. Pelita hides the operator window while presenting. Anyone watching the shared desktop can see the operator window before you enter this mode and after you exit.

Use **Enter** to Take the selected item, **Page Up** or **Page Down** to Take an adjacent playlist item, and **Esc** to leave this mode. Rehearse these controls before worship.

## Keyboard controls

With focus outside a text field: **Enter** Takes the selected item; **Left** and **Right** move between live slides; **B** toggles Black; **R** Restores; **C** Clears. Select **Keyboard shortcuts** at the top of the app to see the current list.

## If the projector disconnects

Pelita suspends output when it loses the display. Reconnect the projector, press **Refresh displays**, choose the intended display, and press **Confirm display** again. Verify the output is black, select the item you want, and press **Take**. Check the physical screen before resuming the service. See [Troubleshooting](troubleshooting.md) if the display does not reappear.
