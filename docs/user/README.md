# Pelita user guide

Pelita helps one operator prepare a service playlist and control what appears on the audience display. These guides describe the current alpha app.

1. [Getting started](getting-started.md): download, open, and show your first slide.
2. [Preparing a service](preparing-a-service.md): build a Sabbath playlist and check media.
3. [Presenting](presenting.md): connect the projector and control the live output.
4. [Media support](media-support.md): choose files Pelita can import and prepare fallbacks.

Need help? Read [Troubleshooting](troubleshooting.md) or the [FAQ](faq.md). For plans and technical details, see [Developer Documentation](../developer/README.md).
