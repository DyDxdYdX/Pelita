# Operator workflows

## Prepare the Sabbath service

1. Create a service playlist or duplicate an earlier service.
2. Add opening hymns, Scripture text, announcements, special music, a sermon deck or video, and closing hymns. Assign an MP3 to a lyric deck when accompaniment is needed.
3. Reorder the items and run preflight. Resolve missing assets and unsupported media before the service. For a PowerPoint deck, export to PDF ahead of time when direct conversion is unavailable or looks incorrect.
4. Preview slides and test audio privately before projection. Save and reopen the playlist offline to verify it is ready.

## Run the service

1. Select and verify the projector using a neutral identification frame. On a mirrored display, use the content-only window and its keyboard controls. Opening the operator interface on a mirrored desktop makes it visible to the audience.
2. Preview the opening item and select **Take**. Advance or reverse slides while accompaniment continues. Use explicit transport controls to pause, resume or restart.
3. Use **Black** to conceal output temporarily. **Restore** reveals the existing frame. **Clear** removes the frame and stops the current transport. Prepare and Take the next item when ready.
4. If the projector disconnects, verify the replacement target and reopen the output in black before taking a prepared item. Pause or resume accompaniment explicitly. If a media item fails, choose a prepared fallback or skip it.

## Find and choose a song · Phase 2

Select a songbook or search across collections. Type a title, number, or lyric fragment. Check the book name and song number, then choose the preferred available variant, such as lyric slides with accompaniment. Preview before queuing or taking it. For missing files, relink or choose a different variant.

## Manage a songbook · Phases 3 and 4

Import a local pack in Phase 3. Review publisher, license, version, and compatibility before activation. Phase 4 adds registry search, downloads and updates. Installed packs remain available offline. Disabling or uninstalling a pack previews the affected playlist entries and gives the operator a chance to cancel. See [extension lifecycle](../architecture/extension-system.md).
